5) dependencies are packages required for the application to run in production, while devDependencies are packages needed only during development.

6) 1️⃣ package.json શું છે?

package.json તમારા project ની information + dependencies list રાખે છે.

એમાં સામાન્ય રીતે આ વસ્તુઓ હોય છે:

Project નું નામ

Version

Scripts (start, dev, build)

Dependencies (કયા packages install છે)

ઉદાહરણ:

{
  "name": "fruitkha-mern",
  "version": "1.0.0",
  "scripts": {
    "start": "node server.js",
    "dev": "nodemon server.js"
  },
  "dependencies": {
    "express": "^4.18.2",
    "mongoose": "^7.0.0",
    "cors": "^2.8.5"
  }
}

7) package-lock.json automatically npm generate કરે છે.

એમાં packages ના exact versions + dependency tree store થાય છે.

Example:

{
  "name": "fruitkha-mern",
  "lockfileVersion": 3,
  "dependencies": {
    "express": {
      "version": "4.18.2"
    }
  }
}

👉 એટલે package-lock.json એ exactly કયો version install થયો છે તે lock કરે છે.

10) Difference between api and restful api?

A normal API is any interface that allows communication between systems, while a RESTful API follows REST architectural principles such as resource-based URLs, proper HTTP methods, stateless communication, and standard structure.

Normal API
/getAllProducts
/addNewProduct
/updateProduct
/removeProduct


RESTful API
GET /products
POST /products
PUT /products/:id
DELETE /products/:id

11) What is difference between authentication and authorization?

Authentication verifies user identity, while authorization determines what actions that authenticated user is allowed to perform.
